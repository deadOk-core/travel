# TravelBlog — Блог для путешественников

**Ссылка на результат:** [https://deadok-core.github.io/travel-production/](https://deadok-core.github.io/travel-production/)

## Описание проекта

TravelBlog — веб-приложение для общения и обмена опытом среди путешественников. Пользователи могут оставлять комментарии, делиться фотографиями и просматривать комментарии других пользователей. Для реализации проекта TravelBlog разработан фронтенд на React, который взаимодействует с существующими API-эндпоинтами. В проекте реализованы следующие функциональные модули:

- Страницы авторизации и регистрации
- Основная страница со списком постов «Там, где мир начинается с путешествий»
- Страница поста «Детальная страница с блоком отзывов»
- Форма создания нового поста
- Страница «Профиль пользователя» с возможностью редактирования данных
- Форма создания комментария
- Навигационный интерфейс с хедером и функциональностью выхода

Разработка осуществлялась в соответствии с предоставленным макетом и документацией по API, доступной в Swagger.

## Функциональные возможности

### Страницы авторизации и регистрации

**Страница регистрации:**

- Поля: email, пароль, подтверждение пароля
- Валидация: email должен быть валидным, пароли должны совпадать
- Метод: POST-запрос к эндпоинту `/api/register` для создания нового пользователя

**Страница авторизации:**

- Поля: логин (email), пароль
- Метод: POST-запрос к эндпоинту `/api/login` для авторизации пользователя

### Основная страница со списком постов

- Отображение списка карточек с заголовками, кратким описанием, страной и городом
- Метод: GET-запрос к эндпоинту `/api/posts` для получения списка карточек
- Возможность перехода на детальную страницу поста
- Возможность создания нового поста (только для авторизованных пользователей)

### Детальная страница с блоком комментариев

- Отображение полной информации о посте: фотография, заголовок, описание и информация о пользователе
- Метод: GET-запрос к эндпоинту `/api/posts/{id}` для получения информации о посте по ID
- Возможность оставлять комментарии для авторизованных пользователей
- Отображение всех комментариев пользователей

### Форма создания поста

- Поля: заголовок, описание, фотография (JPEG или PNG), страна, город
- Валидация всех полей
- Метод: POST-запрос к эндпоинту `/api/posts`

### Профиль пользователя

- Возможность изменения пароля (PATCH-запрос к `/api/user/password`)
- Редактирование персональных данных: Ф. И. О., город, фотография, краткое описание
- Метод: POST-запрос к эндпоинту `/api/user`
- Просмотр информации о пользователе (GET-запрос к `/api/user`)

### Форма создания комментария

- Поля: имя, комментарий
- Валидация всех полей
- Метод: POST-запрос к эндпоинту `/api/posts/{id}/comments`

### Навигация и интерфейс

- Хедер сайта с информацией о пользователе
- Возможность выхода из аккаунта (GET-запрос к `/api/logout`)
- Просмотр постов доступен всем пользователям
- Добавление постов и комментариев — только для авторизованных

## Запуск проекта локально

1. Клонируй репозиторий:

   ```bash
   git clone git@github.com:deadOk-core/travel.git
   ```

2. Перейди в папку проекта:

   ```bash
   cd travelblog
   ```

3. Установи зависимости:

   ```bash
   npm i
   ```

4. Убери строчку basename="/travel-production" из src/App.tsx:

    ```tsx
    // Было:
    <BrowserRouter basename="/travel-production">

    // Должно стать:
    <BrowserRouter>
    ```

5. Запусти локальный сервер:
   ```bash
   npm run dev
   ```
